## En français

Créez des archives REA, consultez leur contenu et extrayez seulement les éléments nécessaires. Le catalogue permet d’explorer une archive avant l’extraction.

### Fonctionnalités

- Création, consultation et extraction sélective
- Catalogue consultable et options de protection lorsqu’elles sont activées
- Outil en ligne de commande et guide Linux

### Disponibilité

Application pour macOS et CLI Linux pour Debian/Ubuntu et systèmes compatibles AMD64.

- [Voir les téléchargements sur rea.com.co](https://rea.com.co/fr/applications/rea-archiver/download/)

- [Guide d’installation Linux](https://rea.com.co/fr/applications/rea-archiver/install-linux/)

## In English

Create REA archives, browse their contents, and extract only what you need. The archive index lets you inspect contents before extracting.

### Highlights

- Create, browse and selectively extract
- Browsable archive index and optional protection
- Command-line tool and Linux installation guide

### Availability

macOS app and Linux CLI for Debian/Ubuntu and compatible AMD64 systems.

- [Downloads on rea.com.co](https://rea.com.co/en/applications/rea-archiver/download/)
